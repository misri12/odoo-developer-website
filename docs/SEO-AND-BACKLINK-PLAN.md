# JTL-Wawi page: SEO and ethical backlink plan

## New landing page
- URL: `/jtl-wawi-odoo-connector`
- Primary intent: JTL-Wawi to Odoo connector / migration
- Supporting intents: JTL-Wawi Odoo integration, JTL-Wawi SQL Server import, JTL-Wawi product migration
- Page includes unique title and description, canonical URL through the shared layout, Open Graph/Twitter image, breadcrumbs, WebPage/Service/BreadcrumbList/FAQPage JSON-LD, internal links, and a project CTA.

## Accuracy rules
- Describe the current demonstrated scope as product-data import with mapping, validation, dry run, and create-only / create-and-update modes.
- Do not claim real-time or bidirectional stock/order sync unless implemented and verified for the target setup.
- Do not claim official JTL or Odoo partnership, guaranteed compatibility, customer results, or performance improvements without evidence.
- Keep the generated connector artwork labeled as an illustration, not a product screenshot.

## Ethical link acquisition
1. Publish a technical README or public project overview with architecture, supported scope, setup guidance, limitations, and the relevant portfolio page link. Do not publish credentials, customer data, or proprietary source code.
2. Submit genuinely distributable Odoo modules to the official Odoo Apps platform only when they meet its listing rules. Do not describe a service page as an official app listing.
3. Write original technical material on SQL Server-to-Odoo mapping, safe dry runs, source identifiers, and migration validation. Link to the page when it is relevant to the article.
4. Contact Odoo implementation agencies and JTL ecosystem consultants with a personalized, useful collaboration proposal. Ask for a link only where it is editorially relevant.
5. Maintain accurate professional profiles and relevant business directories. Avoid bulk directory submissions, automated comments, paid link schemes, fabricated reviews, and irrelevant guest posts.

## Measurement
- Verify the deployed canonical and sitemap URLs after each deployment.
- Submit the sitemap in Google Search Console and inspect the new page URL.
- Track impressions, clicks, referring domains, CTA clicks, and qualified project inquiries monthly.
- Change titles and content based on actual query data, not guessed search volumes.
